# Product context

Unraid users drop a work folder such as `One Piece/Chapter 001` into the inbox. The first confirmed import stores that work's profile. Later stable chapters pack themselves into that profile's output folders. Kavita points only at the output.

The whole setup happens in the WebUI. A successful import moves the source out of the inbox after the output is validated. Ambiguous chapter names fail visibly and are never guessed.
