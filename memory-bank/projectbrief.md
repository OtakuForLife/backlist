# Backlist

Self-hosted Docker app with a WebUI. It watches an inbox of manga page images and writes one CBZ per chapter folder for Kavita.

Input: `/input/{Series}/{Chapter}/*.{jpg,png,webp,...}`

Output: `/output/Manga/{Series}/{Series} Volume 1 Chapter 0001.cbz`

Not in scope: downloaders, metadata, Kavita API, accounts, a reader.
